# Verbal Morphology

## Finite template

`(DIRECTION) (OBJECT) STEM (AUX/DERIV) AGENT (DISCOURSE) TENSE (ASPECT)`

There is no dedicated verbal applicative slot: instrumental and benefactive meanings are expressed through the nominal case system.

## Stem grades

| Grade | Form | Function |
|---|---|---|
| NONFINITE | `-a-` | nonfinite stem |
| LINKING / ATTRIBUTIVE | `-e-` | linking and attributive stem |
| REALIS | `-u-` | realis |
| IRREALIS | `-i-` | irrealis |

The alternating stem vowel is always final in the root/stem. A lexical root such as `kat` becomes verbal `kata`; subsequent grades produce forms such as `kate`, not an internally altered `kati` followed by another suffix.

These grades are independent of directional `i-` and `a-`.

## Direction

- `i-` = toward / goalward
- `a-` = away / sourceward
- `Ø` = neutral

Directional morphology is **verbal**. It is not a prefix attached to the noun. In directional case constructions, the noun carries the relevant spatial case suffix and the finite verb carries `i-` or `a-`. With SOV order, the construction is therefore:

- **ALL:** `S O-LOC i-VERB`
- **ABL:** `S O-LOC a-VERB`

More generally, spatial case polarity is realized compositionally across the noun and verb: `S O-SPATIAL-CASE i-/a-VERB`.

If a vowel is required for NONLOCAL without direction, `e-` may serve as support.

## Object slot

There is exactly one object slot:

| Marker | Function |
|---|---|
| `Ø` | LOCAL object |
| `n-` | NONLOCAL object |
| `s-` | REFLEXIVE |
| `r-` | RECIPROCAL |

The overt object remains a separate noun phrase in SOV clauses; the object marker is part of the verb. Directional case suffixes likewise remain on the overt noun phrase.

## AUX / DERIV roots

The following light roots are available in the AUX/DERIV slot and take the linking `-e-` grade:

| Root | Basic lexical meaning | AUX form | Semantic value |
|---|---|---|---|
| `*r` | go | `-re-` | progressive |
| `*k` | hold | `-ke-` | continuative |
| `*m` | live / dwell / stay | `-me-` | habitual |
| `*s` | cut / remove | `-se-` | inchoative |
| `*t` | transfer | `-te-` | opposite of inchoative |

AUX/DERIV morphology and final verbal aspect are separate slots and may co-occur.

## Agreement

| Person | Marker |
|---|---|
| 1SG | `-k-` |
| 2SG | `-t-` |
| 3SG | `-p-` |

There is no verbal plural agreement. Plural number is distinguished through pronouns.

## Discourse / mood slot

| Marker | Function |
|---|---|
| `-h-` | EXCLAMATIVE |
| `-y-` | INTERROGATIVE |

`-h-` is historically associated with `*h` 'say/blow'; it is not a realis marker.

## Tense

- `-i-` = NONPAST
- `-a-` = PAST

## Aspect

- `Ø` = IMPERFECTIVE
- `-n` = PERFECT

## Established forms

`kerurekin` = `keru-re-k-i-n` (CARRY.REAL-GO.AUX-1SG-NONPAST-PERF).

`ku-p-i > kupi > kuhi > kui` demonstrates the 3SG realis/nonpast form `kui`.

`ku-t-y-i > kutyi > kutye` demonstrates interrogative `-y-` plus NONPAST `-i`, with phonological repair because `-yi` is prohibited.

`hukka < hu-k-h-a` is an established example of the discourse slot; exact lexical/derivational interpretation should remain tied to the relevant root history.
