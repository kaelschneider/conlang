# Test Clauses

**Status:** DEVELOPMENTAL — generated for morphosyntactic testing; not canonical.

**Purpose:** Initial test corpus for testing the currently established morphology and provisional SOV syntax. These examples deliberately exercise unresolved areas without silently canonizing them.

## 1. Simple transitive

`Neku kerande kui.`  
`ne-ku kerande ku-i`  
1SG-ERG container ABS hold.REAL-NONPAST  
**Intended:** “I hold the container.”

**Tests:** SOV order; explicit ERG subject; ABS object; established realis/nonpast verb.

## 2. Second-person transitive question

`Seku kerande kutye?`  
`se-ku kerande ku-t-y-e`  
2SG-ERG container ABS hold-2SG-INTERROG-LINK  
**Intended:** “Do you hold the container?”

**Tests:** SOV order; interrogative discourse slot; 2SG agreement; existing question pattern. The final surface form remains subject to phonological testing.

## 3. Stative predicate

`Kerande sarui.`  
`kerande sar-u-i`  
container large-REALIS-NONPAST  
**Intended:** “The container is large.”

**Tests:** subject + predicate order; realis/nonpast stacking.

## 4. ALL: movement toward a location

`Neku kerande-te irui.`  
`ne-ku kerande-te i-ru-i`  
1SG-ERG container-LOC toward-go.REAL-NONPAST  
**Intended:** “I go to/toward the container.”

**Tests:** canonical SOV directional construction **S O-LOC i-VERB**. `-te` is nominal LOC morphology; `i-` is verbal directional morphology. Together they surface the ALL meaning compositionally. The directional marker is not attached to the noun.

## 5. ABL: movement away from a location

`Neku kerande-te arui.`  
`ne-ku kerande-te a-ru-i`  
1SG-ERG container-LOC away-go.REAL-NONPAST  
**Intended:** “I go from/away from the container.”

**Tests:** canonical SOV directional construction **S O-LOC a-VERB**. `-te` is nominal LOC morphology; `a-` is verbal directional morphology. Together they surface the ABL meaning compositionally.

## 6. Comitative

`Neku seme kui.`  
`ne-ku se-me ku-i`  
1SG-ERG 2SG-COM hold.REAL-NONPAST  
**Intended:** “I hold [it] with you.”

**Tests:** SOV order; COM on the overt animate associate; verbal agreement. Exact object interpretation remains provisional.

## 7. Instrumental

**No secure clause yet.** The current case system identifies inanimate `-me` as instrumental, but the corpus does not yet contain a sufficiently secure instrumental noun + verb combination to serve as a clean test.

**Tests:** reserve instrumental canonization until a natural clause is generated with an established inanimate noun.

## 8. Perfect event

`Neku kerurekin.`  
`ne-ku keru-re-k-i-n`  
1SG-ERG carry.REAL-PROG-1SG-NONPAST-PERF  
**Intended:** “I have been carrying [it].”

**Tests:** established complex verbal form; AUX + agreement + tense + aspect stacking. The overt object is omitted here, so the clause should not be used as evidence for a specific object realization.

## 9. Attributive modifier

`Sare kerande.`  
`sare kerande`  
large.ATTR container  
**Intended:** “the large container.”

**Tests:** attributive modifier preceding noun.

## 10. Plural pronoun

`Men kerande kui.`  
`men kerande ku-i`  
1PL container ABS hold.REAL-NONPAST  
**Intended:** “We hold the container.”

**Tests:** explicit plural pronoun without verbal plural agreement.

## What this corpus tests

| Area | Initial result |
|---|---|
| Basic word order | SOV is supported by the current examples, but needs more independent clauses |
| ABS/ERG | Explicit ERG/ABS combinations are morphologically straightforward |
| Person/number | Plural pronouns can be tested without verbal plural agreement |
| Questions | `-y-` can be tested, but surface repair must be tracked |
| Verbal direction | `i-` / `a-` are placed on the verb; directional spatial meaning is compositional with the noun's spatial case suffix |
| COM polysemy | Animate COM vs. inanimate INST needs explicit noun referents in future tests |
| Verb stacking | `kerurekin` provides an established complex-form test |
| Genitive | **Not resolved by these examples**; requires a matched noun-phrase test |
| Negation | **Not tested**; negative morphology is not yet canonical |
| Split-S | **Not resolved**; requires matched animate/inanimate and volitional/non-volitional clauses |
